# Frozen material

Nothing here is current. This folder keeps code and documents from earlier cycles so the
record stays reproducible, not because they are still used.

- `tcf/`: the v0.5 engine (columnar levels L0 to L3), superseded by the compositional core.
- `llm-benchmark/`: the v0.5 LLM benchmark harness, an accessory line of research.

**The current code is in [`../src/tcf/`](../src/tcf/)** and the current documentation in
[`../docs/`](../docs/). If you followed a link here looking for how TCF works today, start
at the [README](../README.md).
